# O resto do mapa
semana: 9
entrega: nenhuma — este é o mapa, não a trilha

O roadmap.sh de backend tem 166 tópicos. As oito semanas acima são os que tocam
o seu trabalho de automação e análise. O resto está aqui, sem enfeite: nada foi
escondido, e nada foi posto na sua frente antes da hora. Quando um projeto seu
esbarrar num destes, ele deixa de ser teoria — e aí vale abrir.

## conceitos
- quando a mesma consulta repete muito: cache (Redis, Memcached, cache de HTTP)
- quando a tarefa demora demais para a requisição: filas (RabbitMQ, Kafka)
- quando o deploy precisa ser automático: CI/CD
- quando alguém de fora acessa: servidor web (Nginx, Apache), OWASP, TLS, hashing de senha
- quando o volume cresce: réplica, sharding, teorema CAP, NoSQL
- quando o sistema vira vários: monolito × microsserviços, SOA, twelve-factor
- quando precisa buscar texto de verdade: Elasticsearch, Solr
- quando a tela precisa atualizar sozinha: WebSockets, SSE, long polling
- quando não dá para adivinhar o que quebrou: observabilidade, métricas, tracing
