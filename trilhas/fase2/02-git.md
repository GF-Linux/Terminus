# Git e GitHub
semana: 2
entrega: seu script versionado, com histórico que você entende

Git é a rede de proteção de quem escreve código sozinho. Não é burocracia de
equipe: é poder mudar tudo sabendo que dá para voltar — e é o que faz "eu quebrei
e não sei o que mudei" deixar de existir.

## conceitos
- repositório, `add`, `commit`: o que é uma fotografia do projeto
- mensagem de commit que o você-de-daqui-a-três-meses entende
- `status`, `diff`, `log` — ler antes de mexer
- desfazer: `checkout`, `restore`, `revert` (e por que `reset --hard` assusta)
- ramo: experimentar sem estragar o que funciona
- remoto: `push`, `pull`, e o que o GitHub acrescenta
