# Como a internet funciona
semana: 4
entrega: entender uma requisição do começo ao fim

Antes de consumir uma API você precisa saber o que acontece quando um programa
"fala" com outro. É o alicerce de tudo que vem depois — e é o que faz erro de
rede deixar de ser mágica.

## conceitos
- cliente e servidor: quem pede, quem responde
- HTTP: método, cabeçalho, corpo, código de status
- o que significa 200, 301, 401, 403, 404, 429, 500
- DNS: como um nome vira um endereço
- HTTPS e por que certificado importa
- JSON: o formato em que quase toda API responde
